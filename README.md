# めぐとおのゆーどこかにビューン デジタルパンフレットIN青森

ふたりだけで見る、青森旅行の静的デジタルパンフレットです。
ブラウザで `index.html` を開くだけで動きます。

今回の見どころとして、新幹線往復1万円、青森駅のタイムズカーシェア、返却後の地酒タイムをハイライトカードにまとめています。
青森MAPでは、今回行くスポットと有名・次回候補スポットをかわいいピンで表示します。

## パスワード設定

`app.js` の `TRIP_CONFIG` を編集してください。

- `coupleDateMMDD`: 付き合った日を4桁で入力します（例：1月1日 → `0101`）
- `departureDateMMDD`: 次の旅行の出発日を4桁で入力します（今回の青森旅行は `0613`）
- `passwordOverride`: 任意の8桁パスワードを直接指定したい場合だけ入力します

パスワードは、基本的に `coupleDateMMDD + departureDateMMDD` の8桁です。
付き合った日が1月1日で旅行出発日が6月13日なら `01010613` になります。

## 旅程やリンクの修正

旅程・メモ・公式リンクは `app.js` の `TRIP_CONFIG.days` にまとめています。
時刻やスポットを変えたい場合は、該当する `time` / `place` / `note` / `link` を編集してください。
料金・移動手段などの強調カードは `index.html` の `highlight-card` を編集してください。
青森MAPは国土地理院の標準地図タイルを読み込み、`app.js` の `TRIP_CONFIG.mapSpots` にある緯度経度でピンを重ねています。スポットの名前・アイコン・リンク・緯度経度を編集できます。地図タイルは外部配信のため、初回表示時はネットワーク接続が必要です。

## ローカル確認

```bash
python3 -m http.server 4173
```

起動後、ブラウザで `http://localhost:4173` を開いて確認できます。

## PWA / ホーム画面追加

`manifest.webmanifest` と `sw.js` によりPWAとして動作します。ログイン成功後、対応ブラウザでは「ホームに追加」案内が表示されます。iPhoneの場合は共有メニューから「ホーム画面に追加」を選択してください。

## PRアップロード時の注意

このリポジトリではバイナリファイル非対応のPR環境でも扱えるよう、PWAアイコンはPNGではなくテキスト形式のSVG（`icons/icon-192.svg`, `icons/icon-512.svg`）にしています。
